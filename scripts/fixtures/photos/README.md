# HEIC sintètic de regressió

`synthetic.heic`: icona del repositori `icons/icon-192.png` (192×192), convertida al Mac amb `sips -s format heic`. Sense fotografies ni metadades personals de viatgers. El mateix contenidor HEIF/HEIC es prova amb les extensions i MIME `heic` i `heif`.

SHA-256: `a21b8f7880b376f5407b861faa9bd804f357c3852c03d551d6c71358df3c61b3`.

No representa totes les variants HEIC, Live Photos, HDR ni fotos de 48 MP. La validació física requereix originals d'iPhone, sense publicar-los al repositori.
